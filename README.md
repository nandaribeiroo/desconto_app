# desconto_app

Sistema de pedidos de e-commerce com aplicação de diferentes tipos de desconto.

## Objetivo

Desenvolver uma aplicação Python organizada em camadas, separando as responsabilidades de cada parte do sistema.

## Funcionalidades previstas

- Receber pedidos de clientes.
- Aplicar descontos conforme o tipo de cliente ou campanha.
- Salvar pedidos.
- Listar pedidos registrados.
